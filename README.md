# MMD Jiggle Bones

MMD Jiggle Bones 提供 RGBA 式胸部物理移植与胸部尺码分析功能。

插件可以将 RGBA 式胸部物理应用于包含胸部权重的模型，并根据胸部尺码分析结果自动调整摇晃幅度等物理参数。

无论角色胸部大小，无论动作幅度剧烈或平缓，均可表现出较为适宜的胸部物理效果。

## 使用前提
- 模型本身含有胸部骨骼及对应权重。
- 模型本身含有“上半身2”和“首”骨骼。
- （可选）腕、ひじ、手首骨骼拥有对应的追踪骨骼类型的刚体。

## 使用限制
- 生成的模型无法在Blender、MMM、NexGiMa中直接进行物理烘焙，如需烘焙，请使用MMD桥流程。

## 使用方法
1. 安装插件后，在 Blender 的 N 面板中找到插件界面。
2. 填写“模型目录”参数，然后点击“执行”按钮。
3. 使用插件生成的模型进行后续流程。

## 注意事项
- 若双臂挤压胸部导致胸部之间发生穿模，可适当减小插件的刚体缩放参数。
- 若胸部与饰品的非物理部分发生穿模，可降低摇晃幅度，或隐藏发生穿模的部位，例如《绝区零》中的爱丽丝官模。
- 若胸部与饰品的物理部分发生穿模：
  - 可能是碰撞组设置异常，可尝试调整插件的碰撞组参数，例如《崩坏：星穹铁道》中的飞霄官模。
  - 可能是饰品刚体尺寸过大，可适当减小插件的刚体缩放参数，以缩小胸部刚体尺寸，例如 Tda 式初音ミク。也可以在 PmxEditor 中设置饰品刚体与胸部刚体不发生碰撞，例如《终末地》中的梨诺。
- 不建议在生成模型后再导入 Blender 进行缩放并重新导出。这样会导致开启物理前后的胸部默认姿态不一致，可能出现胸部下偏或上翘的问题。如需缩放，请在执行插件前完成；如果已经缩放并重新导出，可重新执行插件以恢复胸部物理设置。
- 若提示未找到胸部骨骼，但模型实际包含胸部骨骼及对应权重，可能是由于骨骼命名不规范导致。可在“骨骼扩展”参数中手动填写胸部骨骼名称，使插件能够正确识别。
- 当胸部尺寸较大且胸型为自然下垂时，“胸部高度”的测量结果可能与实际情况存在偏差。如出现异常，请手动调整摇晃幅度。
- 部分奶盖类角色或穿着小马甲的角色，可能由于胸部定位偏差导致摇晃幅度过大。如出现此类问题，请手动调整摇晃幅度。
- 由于不同模型的骨骼结构与权重分布存在差异，个别模型在剧烈运动时可能出现胸部异常扭曲。如出现此类问题，请手动调整摇晃幅度。
